# Gumi, your ai assistant
###

# How do i install Gumi?
**in simple steps!**
* Open releases (or my [itch](https://potipek.itch.io/gumi))
* Download zip
* Open the .exe
* Configure the AI (openai compatible endpoint)
* **AND DONE! You can now use it :)**
###
# Who is this project for and what is it for?
* It is for someone who wants to have an interactive pet on his desktop
* Also for everyone else!
###
# Features:
* AI - plug in your api key and you can chat with him (only text no photos and etc :( )
* On/Off switch - Toggle the movement and animations
* Drag animation - When you drag Gumi, he does some silly animations!
* He says random things too!
